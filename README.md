# 🤖 ChatPDF Inteligente — Assistente com IA

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático da formação DP-100 da Microsoft, na plataforma DIO.

A proposta é explorar o uso da Inteligência Artificial para facilitar a consulta de informações presentes em documentos, utilizando conceitos de IA generativa, embeddings e busca vetorial.

## 🎯 Objetivo

Desenvolver a proposta de um chatbot capaz de responder perguntas com base no conteúdo de documentos fornecidos pelo usuário.

## 📂 Estrutura do projeto

```text
chatbot-pdf-inteligente/
│
├── inputs/
│   └── documento.txt
│
└── README.md
```

## 🧠 Conceitos estudados

- Inteligência Artificial Generativa.
- Processamento de documentos.
- Embeddings.
- Busca vetorial.
- Recuperação de informações.
- Chatbots baseados em documentos.

## 💡 Aplicações práticas

Essa solução pode ser utilizada para:

- Consultar documentos com mais rapidez.
- Encontrar informações importantes.
- Apoiar estudos e pesquisas acadêmicas.
- Facilitar o acesso ao conhecimento.
- Melhorar a produtividade.

## 📊 Aprendizados

Durante este desafio, pude compreender como a Inteligência Artificial pode ser utilizada para transformar documentos em fontes de conhecimento consultáveis.

Também conheci a importância dos embeddings e da busca vetorial para recuperar informações relevantes e fornecer respostas contextualizadas.

- Implementar a busca vetorial.
- Desenvolver uma interface de chat.
- Realizar testes com diferentes documentos.
